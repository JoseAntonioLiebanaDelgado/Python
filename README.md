# 🐍 Python Projects

Este repositorio contiene diferentes proyectos y ejercicios realizados en **Python**, orientados a la práctica de programación, uso de librerías y desarrollo de pequeños programas interactivos.

---

## 📂 Estructura del repositorio

- **BasketPlayers/**  
  Proyecto que trabaja con datos de jugadores de baloncesto.  
  Incluye archivos `.csv` y `.json` para importar y procesar información.

- **Ejercicio Python Meteorología/**  
  Ejercicio basado en el análisis de datos meteorológicos.  
  Contiene documentación y ficheros en PDF relacionados.

- **NumPy_1/**  
  Prácticas con la librería **NumPy** aplicadas a datasets meteorológicos.  
  Incluye varios archivos `.csv` y scripts en Python.

- **PythonMeteocat/**  
  Proyecto que consume datos meteorológicos de **Meteocat**.  
  Se procesan ficheros `.csv` con información climática.

- **Python_Pygame_1/**  
  Minijuego creado con **Pygame**, utilizando imágenes y audio.  
  Ejemplo práctico para aprender desarrollo de videojuegos en Python.

- **pythonProject/**  
  Carpeta de ejercicios varios: funciones, expresiones lambda y pruebas generales.

---

## 🛠️ Tecnologías utilizadas

- Python 3.x  
- Librerías: NumPy, Pygame  
- Archivos CSV y JSON para manipulación de datos  

---

## 🚀 Objetivo

Este repositorio agrupa prácticas y pequeños proyectos realizados durante el aprendizaje de Python, con el objetivo de mejorar la lógica de programación, la gestión de datos y la creación de aplicaciones interactivas.
